Google Chrome
------------------------------------------------------

-Hardware:
 It works well on mobile phones and computers with RAM and a CPU.

-Software:
 It is a web browser used to search and collect information and
 runs on Operating Systems like Windows, Andriod and more.

-Data:
 Is the collection of questions in the search bar, website data
 like cookies and more

-People:
 The human stakeholders are the Users of chrome to search on
 websites for research, Google developers that updatee and
 manage the web browser as well as cyber security team for
 protection and etc.

-Process:
 The proccess starts by user input in the search bar, then chrome
 checks and processes that question or input, next it connects
 to the internet which pulls information from websites relating to
 the user input.It finally processes the websites data and displays
 the output of the web page so the user can access the information.

 The raw data collected: can be the browsing history of a user that
 visited a university webisite 5 times during the month April.

 The system transformation in chrome stores and sorts the website vists from
